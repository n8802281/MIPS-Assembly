# MIPS-Assembly
MIPS Assembly practice assignments focused on control flow, recursion, and algorithmic logic, including summation, pattern printing, and prime number analysis.

# MIPS Assembly Programming Practice

This repository contains MIPS Assembly programs developed as part of coursework and self-study exercises. These programs explore core assembly language concepts including recursion, conditionals, memory access, and control flow.

## 📂 Implemented Programs

- **Lab1a.asm**  
  Recursive summation using a stack and syscall  
  (e.g., sum(1...n))

- **Lab1b.asm**  
  Pattern output: prints an isosceles triangle using loops and conditional logic

- **Lab1c.asm**  
  Prime number detection and nearest prime search (both upward and downward)

## 🧠 Concepts Practiced

- Stack management using `$sp`, `$ra`  
- Register operations and parameter passing (`$a0`, `$v0`, etc.)  
- Syscall-based I/O  
- Nested loops and branching

## 🔧 Environment

- Architecture: MIPS  
- Assembler: [MARS (MIPS Assembler and Runtime Simulator)](http://courses.missouristate.edu/kenvollmar/mars/)

## 📌 Notes

These assignments were written to strengthen my understanding of low-level programming and execution flow. Each `.asm` file includes comments explaining logic and register usage.
